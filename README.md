# telecom-analytics-demo

Небольшой демонстрационный набор скриптов для портфолио: типовые задачи, которыми
я занимаюсь как Product Owner в B2B-телекоме — разбор номерной ёмкости и подготовка
управленческой отчётности.

**Данные полностью синтетические.** Никакой информации реальных клиентов или компании здесь нет.

## Что внутри

| Файл | Задача |
|------|--------|
| `phone_categorizer.py` | Разбор списка номеров (MSISDN) на категории «красоты» по маске и повторам цифр |
| `report_builder.py` | Сборка Excel-отчёта по продуктам из CSV: сводка, условное форматирование, цветовая заливка |
| `data/sample_numbers.csv` | Пример номерной ёмкости |
| `data/sample_kpi.csv` | Пример помесячных метрик по продуктам |

## Запуск

```bash
python3 -m pip install -r requirements.txt

python3 phone_categorizer.py data/sample_numbers.csv
python3 report_builder.py data/sample_kpi.csv out/report.xlsx
```

## Категории номеров

Скрипт присваивает каждому номеру одну категорию (первую подходящую сверху вниз):

- `AAAAAA` — 6+ одинаковых цифр подряд в абонентской части
- `ABABAB` — периодический узор из двух цифр
- `AAABBB` — две тройки одинаковых цифр
- ` +100 / +1000` — «круглый» номер
- `AAA` — тройка одинаковых цифр
- `pair-rich` — 3+ пары одинаковых цифр
- `standard` — всё остальное

Логика намеренно простая и читаемая — это витрина подхода, а не продовый классификатор.
